# 🚀 AI-Powered Career & Resume Copilot

An autonomous AI agent designed to help job seekers optimize their resumes for Applicant Tracking Systems (ATS) and practice role-specific mock interviews. Built seamlessly without traditional coding using LLM orchestration.

## 🛠️ Tech Stack
* **LLM Engine:** Google Gemini 3.5 Flash API
* **Orchestration & UI:** Dify.ai
* **Techniques:** Prompt Engineering, System Instructions, AI Agent Architecture

## ✨ Key Features
1. **ATS Keyword Gap Analysis:** Compares user resumes against target Job Descriptions to identify missing critical skills.
2. **Impact-Driven Bullet Upgrades:** Rewrites weak resume points using the STAR framework (Action + Context + Impact).
3. **Interactive Mock Interviews:** Conducts conversational mock interviews tailored to specific roles and grades answers out of 10.
